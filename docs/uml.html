Emporia Amnesia Class Diagram

The shared classes every group uses, and the classes the groups write themselves. Concrete locations and npcs are shown as generic placeholders.

  • Group-written classes

Reading the diagram

  • Visibility: + public, # protected, - private. A trailing $ marks a static member. Name and Description on Location, Npc and Item are public to read but protected set – only the class itself (or a subclass) assigns them, usually in the constructor.
  • Hollow arrow is inheritance. Dashed hollow arrow is "implements interface". Dashed arrow is a dependency (one class calls the other). Filled diamond is ownership (Game creates its Map, Player and Menu; LocationX creates its NpcA). Hollow diamond is aggregation (Map holds the Locations, a Backpack holds Items).
  • Composition vs inheritance: LocationX has an NpcA (composition) and is a Location (inheritance). NpcA is an Npc. Neither Location nor Npc inherits from the other – IInteractable is what they share.
  • Enum and static: Direction is a fixed set of values; Directions.Label() is a static method that turns one into Swedish text for the menu. Map.Locations is a static field – there is one map – and Map's static constructor fills in every Location's exits once.
  • Where state lives: the Player carries position, backpack and GameOver. Each Location and Npc keeps its own private fields (attempts, SomeFlag) – the room does not know how the bribe went, it asks the guard afterwards.
  • Placeholders: LocationX, LocationY and NpcA stand for any concrete location or character. The shipped examples map them to OutsideDryCleaner / SecurityOffice, ToiletStall and Guard.

    direction TB

    class IInteractable {
        <<interface>>
        +Interact(player)
    }

    class Direction {
        <<enumeration>>
        North
        South
        West
        East
        None
    }

    class Directions {
        <<static>>
        +Label(direction)$ string
    }

    class Game {
        -isDev : bool
        -isRunning : bool
        -map : Map
        -player : Player
        -menu : Menu
        +Start()
        -PlayTurn()
        -ChooseDirection()
        -TryMovePlayer(rowMove, colMove)
        -SearchLocation()
        -TakeItem()
        -Interact()
    }

    class Map {
        +Locations$ : Location[][]
        +GetLocation(row, col) Location
        +PositionExists(row, col)$ bool
        +DirectionsFor(row, col)$ Direction[]
        +DirectionsFor(location)$ Direction[]
    }

    class Menu {
        +Ask(heading, options) int
    }

    class Player {
        +Row : int
        +Col : int
        +Backpack : Backpack
        +GameOver : bool
        +Teleport(className)
    }

    class Backpack {
        +Items : List~Item~
        +Add(item)
        +Has(name) bool
        +Remove(name) Item
        +Print()
    }

    class Item {
        +Name : string
        +Description : string
        +ToString() string
    }

    class Location {
        +Name : string
        +Description : string
        +Directions : Direction[]
        +Items : List~Item~
        +Interact(player)
    }

    class Npc {
        +Name : string
        +Interact(player)
    }

    class LocationX {
        -_npc : NpcA
        -attempts : int
        +Interact(player)
    }

    class LocationY {
        +Interact(player)
    }

    class NpcA {
        +SomeFlag : bool
        +Interact(player)
    }

    IInteractable <|.. Location : implements
    IInteractable <|.. Npc : implements
    Location <|-- LocationX
    Location <|-- LocationY
    Npc <|-- NpcA

    Game *-- Map
    Game *-- Player
    Game *-- Menu
    Player *-- Backpack
    Backpack o-- Item : Items
    Map "1" o-- "*" Location : Locations grid
    Location o-- Item : Items lying here
    Location ..> Direction : Directions
    Map ..> Direction : DirectionsFor
    Game ..> Directions : Label() for the menu
    Game ..> Location : Interact(player)
    Player ..> Map : Teleport looks up Locations
    LocationX *-- NpcA : owns, calls Interact(player)
    LocationX ..> Player : Teleport(), Backpack.Has()
    LocationY ..> Backpack : Add(item) / Remove(name)
